                            **Task 8: Network Traffic Capture and Analysis Using Wireshark**

**Objective**



The objective of this task was to capture and analyze network traffic using Wireshark. The exercise focused on monitoring network communications between a Kali Linux system and a Metasploitable 2 virtual machine, filtering HTTP traffic, and examining packet-level communication.





**Lab Environment**



Attacker / Analysis Machine

\- Kali Linux



**Target Machine**

\- Metasploitable 2



**Network Configuration**

\- VirtualBox Host-Only Network



**Tool Used**

\- Wireshark





**Introduction**



Wireshark is a network protocol analyzer that allows security professionals to capture, inspect, and analyze packets traveling across a network.



It is widely used for:



\- Network troubleshooting

\- Security monitoring

\- Protocol analysis

\- Incident response

\- Traffic inspection



For this task, Wireshark was used to capture HTTP traffic generated while accessing web services hosted on Metasploitable 2.





**Procedure**



*Step 1: Launch Wireshark*



Wireshark was started on Kali Linux and the active network interface (eth0) was selected.



*Step 2: Start Packet Capture*



Packet capture was initiated on the eth0 interface.



During capture, network communications between Kali Linux and Metasploitable 2 were monitored.



*Step 3: Generate Network Traffic*



Traffic was generated by accessing the Metasploitable 2 web server through a web browser.



The following resources were accessed:



\- Home Page (/)

\- DVWA Application (/dvwa)

\- DVWA Login Page (/dvwa/login.php)



*Step 4: Apply HTTP Filter*



The following display filter was used:



```text

http

```



This filter displayed only HTTP-related packets for easier analysis.



*Step 5: Analyze Packets*



Captured HTTP packets were examined to understand client-server communication.

***Security Observations***



***Plaintext Communication***



The captured traffic used HTTP rather than HTTPS.



Because HTTP is not encrypted:



\- Usernames may be exposed

\- Session identifiers may be visible

\- Sensitive information can be intercepted

\- Network monitoring becomes easier for attackers





***Network Visibility***



The packet capture demonstrated how network analyzers can observe:



\- Client requests

\- Server responses

\- Protocol details

\- Communication patterns



This highlights the importance of encrypted communication channels in production environments.





**Importance of Packet Analysis**



Packet analysis is an essential cybersecurity activity because it helps:



\- Detect malicious activity

\- Investigate security incidents

\- Troubleshoot network problems

\- Monitor web applications

\- Understand network behavior



Wireshark provides detailed visibility into communications occurring between systems.





**Findings**



The Wireshark capture successfully recorded communication between Kali Linux and Metasploitable 2.



***The analysis revealed:***



\- HTTP GET requests

\- Successful server responses (200 OK)

\- Redirection responses (301 and 302)

\- Underlying TCP communication

\- Supporting ARP and DHCP traffic



The captured packets provided a clear view of how web requests are transmitted across a network.





**Conclusion**



This task successfully demonstrated the use of Wireshark for capturing and analyzing network traffic. HTTP communications between Kali Linux and Metasploitable 2 were observed and analyzed using display filters.



The exercise provided practical experience in packet capture, protocol analysis, and traffic inspection, while highlighting the security risks associated with unencrypted HTTP communications.
